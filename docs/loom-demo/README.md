# Aurel Loom Demo Assets

This folder contains the prepared Loom demo materials for Aurel.

## Files

- `aurel-product-demo.webm` - Browser-recorded product walkthrough using the live app demo.
- `aurel-simple-animated-demo.webm` - Simplified animated explainer with a dark visual style.
- `aurel-simple-white-demo.webm` - Simplified animated explainer on a white background, with motion transitions and highlighted key words.
- `simple-white-demo.html` - Source HTML for the white animated version.

The recommended version for a non-technical Loom insert is `aurel-simple-white-demo.webm`.
