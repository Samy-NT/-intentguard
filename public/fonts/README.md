This project now uses the free Google Font "Orbitron" for the hero by default.

No font files are required locally; Orbitron is loaded from Google Fonts via CSS. If you prefer to self-host fonts, place them here and update `app/globals.css` accordingly.

If you do add font files, restart the dev server if it's already running.

Note: Do not commit licensed font binaries to the repository unless you have the right to redistribute them.
